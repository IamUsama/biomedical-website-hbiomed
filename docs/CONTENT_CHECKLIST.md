# Content checklist — confirm with the customer before launch

Only publish facts the customer has confirmed. Placeholders in `site.config.json` start with "Replace…".

- [ ] Exact company name and spelling
- [ ] Tagline / one-line description (final wording)
- [ ] Phone (calls) and WhatsApp number — are they the same?
- [ ] Public email address (a Gmail is fine to begin with)
- [ ] Full address and a Google Maps link
- [ ] Opening hours (and days)
- [ ] Areas served (city / province / nationwide)
- [ ] Product groups and typical items; brands represented (only if authorised)
- [ ] Services offered (installation, servicing, repair, maintenance, medical gas pipelines)
- [ ] Short "About" text; any registrations, certifications or licences they want shown
- [ ] Show the NTN / tax number publicly? (`showTaxNumber`)
- [ ] Social profiles (Facebook, LinkedIn, Instagram) if any
- [ ] Privacy contact email
- [ ] Web3Forms access key created with the company email
- [ ] Domain name chosen and purchased by/for the customer
- [ ] Their own photographs (premises, installed equipment, stock) to replace stock images — real photos convert better
